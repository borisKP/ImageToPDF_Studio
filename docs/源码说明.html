关键文件

文件作用
src/app.py窗口、横栏菜单（文件/开始/视图/帮助）、关于对话框、双视图列表、排序、页面/压缩/输出/密码设置、压缩包密码交互、后台转换线程、--selftest 自检。
src/core.pyDPI 解析、页面尺寸计算、Acrobat 式压缩、阅读优先预处理、PDF 加密与书签。
src/archive.pyZIP（含 AES 密码）/ 7Z（含密码）/ RAR（外部 7-Zip 或 WinRAR）解压；防路径穿越、数量与体积上限；统一异常 PasswordRequired / BadPassword。
ImageToPDF_整合版源码.py生成器把 3 个模块内联成的可直接运行单文件（位于 源码交付/，zip 内也含一份）。
scripts/make_source_bundle.py版本号唯一来源 src/app.py → APP_VER；同步文档版本号/日期、重建整合版与 ImageToPDF_源码_v<版本>.zip。
README.md / CONTRIBUTING.md面向使用/开发者的仓库入口与发版规则。

运行 / 测试 / 打包

:: 直接用成品
dist\ImageToPDF_Studio.exe

:: 从源码运行
python -m pip install -r requirements.txt
python src/app.py
python src/app.py --selftest

:: 测试
python tests/test_core.py
python tests/test_archive.py
QT_QPA_PLATFORM=offscreen python tests/test_gui.py

:: 一键打包 EXE + 同步源码交付物
build.bat
ImageToPDF_Studio.spec 顶部把 set_exe_build_timestamp / update_exe_pe_checksum 置为 no-op，用于绕开构建机对成品 exe 的 open(exe,'wb') 写入保护。这两步是可选后处理，跳过不影响运行；在其他机器上可删掉这 3 行。

模块结构与关键实现

模块要点
页面尺寸compute_page_size()：按 px ÷ DPI × 72 = pt 生成页面，每页尺寸可不同；支持固定 DPI、最长边限制、统一纸张。
压缩compress_stream()：双立方下采样 → baseline JPEG → 仅图形类图片尝试调色板 PNG → 与无损流比体积取小；ppi 下限 72。
阅读优先prepare_readable_stream()：统一转 4:4:4 baseline JPEG + 单页像素上限，PDF 内不再有 FlateDecode 图像对象。
加密security_kwargs()：AES-256 / AES-128 / RC4-128 + 用户/所有者口令 + 权限位。
压缩包extract_archive()：pyzipper（AESZipFile）/ py7zr / 外部 7z.exe 或 UnRAR.exe；只导出图片，按文件名自然排序。
界面QMenuBar 四组菜单 + 版本号角标；QStackedWidget 双视图；QThreadPool 异步缩略图；QThread 后台转换；右键菜单与文件拖放。

诊断脚本

  • scripts/diagnose_compression.py —— 解包 PDF 图像对象，查 JPEG SOF marker 与色彩空间。
  • scripts/diagnose_speed.py —— Flate vs DCT 渲染耗时、解压内存、线性化兼容性。
  • scripts/diagnose_webp.py —— WebP 无法直接嵌入 PDF、二次有损代价。
  • scripts/diagnose_casual.py —— 大原图降维到「网站展示副本」级别的体积与渲染对比。

版本演进

版本内容
1.0按图片原尺寸生成 PDF、排序/右键置顶、Acrobat 式压缩、独立 EXE。
1.1左侧「预览小图 / 文字详细信息」视图切换。
1.2PDF 口令保护与权限控制。
1.3修复强压缩导致的移动端异常：强制 baseline JPEG、照片不做 256 色量化、ppi 下限 72。
1.4阅读流畅优先预处理、单页像素上限、移动端一键优化。
1.5「随便看看 · 最小最快」一键档；源码交付物与版本同步机制。
1.6横栏菜单（文件/开始/视图/帮助）与关于对话框、常显版本号；压缩包（ZIP/7Z/RAR，可带密码）导入与一步出 PDF；GitHub 标准仓库结构、MIT 许可、CI 与开源文档。
1.7压缩包解压总体积上限改为可配置（0 不限制～100 GB + 快捷按钮）；超限弹窗询问「继续 / 中止」，不再自动终止；LimitExceeded 与 on_limit 回调。
1.8EXE 体积 75 MB → 52 MB：剔除重复 MuPDF DLL、未使用的 Qt 动态库/插件、ONNX 布局模型、AVIF 解码器、Cryptodome SelfTest；关闭适得其反的 UPX；新增 scripts/analyze_exe_size.py。
1.9新增中英文界面即时切换（src/i18n.py，设置持久化）与浅色 / 深色 / 跟随系统主题（src/theme.py）；菜单新增「设置 → 语言 / 外观」；新增 tests/test_i18n_theme.py。
1.10修复深色主题设置面板的浅灰底纹：theme.apply() 同步设置 Qt 调色板，滚动区与勾选框不再显示系统浅色；底栏去除硬编码白色。
